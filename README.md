# no_work_ide
# Техническая спецификация: IDE-подобное приложение для записи и генерации автотестов на Java 17

**Основной вывод (MVP):**  
Позволить пользователю открывать два окна (WebDriver + панель действий), записывать клики, ввод, селекты, переключения вкладок и сохранять сценарий в JSON, а также воспроизводить его.

***

## 1. Архитектура и стек технологий

Приложение состоит из двух **отдельных** окон OS:
- Окно WebDriver (встроенный Chrome‐браузер с управлением через Selenium).
- Окно приложения (Java-клиент с GUI).

Технологии:
- Java 17, Spring Boot для бэкенда (сервисов управления записью и генерацией).
- GUI: JavaFX (кроссплатформенность, гибкая стилизация, поддержка тем).
- WebDriver: ChromeDriver (поддержка v-последовательности).
- Тестовый стек: Selenium WebDriver, Selenide, JUnit 5, Allure, Lombok.

***

## 2. Запись действий

### 2.1. Типы действий
Поддерживаются:
- Клики (одинарные, двойные).
- Ввод текста (клик на поле игнорируется).
- Выбор из `<select>` или кастомных dropdown.
- Чекбоксы и радиокнопки.
- Переключение вкладок/окон.

Игнорируются:
- Наведение без клика.
- Прочие движения мыши.

### 2.2. Интерфейс записи
- Кнопки «Начать запись» / «Остановить запись».
- При нажатии «Начать» инициализируется ChromeDriver, происходит слушание событий.
- После «Остановить» сценарий сохраняется или готовится к экспорту.

***

## 3. Панель действий

### 3.1. Таблица действий
Столбцы:
- **Action**: тип действия (`click`, `fill`, `select`, `switchTab`).
- **Selector**: локатор (`xpath` или `id`).
- **Value**: вводимый текст или опция.
- **Comment**: комментарий.
- **Element Type**: кнопка, поле, селект, чекбокс, радиокнопка.

### 3.2. Редактирование
- Удаление строк.
- Drag&drop для перестановки.
- Редактирование селектора/значения.
- Кнопка «Проверить» локатор → подсветка элемента жёлтым контуром.
- Пауза записи между действиями.
- Индикатор валидации селектора (крестик + tooltip при отсутствии элемента).

### 3.3. Подсветка элементов
При наведении на строку или нажатии «Проверить» на странице браузера элемент обводится жёлтым контуром; если найдено несколько, подсвечиваются все.

***

## 4. Хранение сценариев

- Формат: **JSON** (описание шагов, URL каждой страницы, селекторы, значения, комментарии).  
- Пример структуры:
```json
{
  "first": {
    "url": "https://...",
    "actions": {
      "click_0":   {"selector":"//...","value":"","comment":""},
      "fill_1":    {"selector":"//...","value":"text","comment":""}
    }
  },
  "second": { ... }
}
```
- Сохранение/загрузка через диалог выбора папки (по умолчанию — рабочий стол в папке “<TestName> (1)”).

***

## 5. Воспроизведение сценариев

- Кнопка «Воспроизвести» в приложении.
- Пошаговое выполнение: подсветка текущего шага в таблице.
- Управление скоростью воспроизведения.

***

## 6. Генерация Java-кода

### 6.1. Фазы

1. **MVP:**  
   - Генерация Java-файла `TestNameTest.java` с одним методом `@Test`.  
   - Импорты из стека: Spring/Selenide/Selenium/JUnit5/Lombok/Allure.  
   - Прямая генерация:
     ```java
     ChromeDriver driver = new ChromeDriver(...);
     open("firstUrl");
     new Button("Add").click();
     new Field("Name").fill("text");
     // ...
     ```
2. **Extended:**  
   - Генерация структуры PageObject без интеграции кастомных классов.
3. **Advanced:**  
   - Интеграция с существующими PageObject-классами и Web-element-библиотекой.

### 6.2. MVP-генерация

- Метод `@Test @DisplayName("TestName") void testTestName() { ... }`.
- Называние переменных:
  - Если локатор по `@data-testid`, берётся его значение.
  - Иначе из `name` в Web-element-классах; fallback `name1`, `name2`.
- Всегда через геттеры:
  ```java
  val page = new Suspends();
  page.getAddButton().click();
  ```
- JSON-сценарий переводится в последовательность вызовов.

### 6.3. Файловая структура экспорта

- Папка: `<TestName>/`
  - `TestNameTest.java`
  - (позже) `SuspendsPage.java`, `Field.java` и т.п.

***

## 7. Интеграция с кастомной библиотекой

### 7.1. Автоподбор элементов

1. Пометка классов PageObject аннотацией:
   ```java
   @PageObjectUrls({"https://...","https://..."})
   public class Suspends { ... }
   ```
2. При генерации автотеста:
   - Сканировать указанный путь `src/main/java/ru/rt/iqhr/pageobject`.
   - По каждой аннотации и xpath-локатору искать совпадения с записанным действием.
   - Если найдено → использовать существующий геттер.
   - Если нет → генерировать вызов `new Select("name").selectOption()`.

### 7.2. Определение типа элемента

- По паттерну кастомных xpath в Web-element-классах (`Select`, `Button`, `Field`, `CheckBoxButton`, `RadioButton`).
- При генерации теста дать пользователю превью кода и возможность правки локаторов/типов перед сохранением.

***

## 8. Переменные в сценарии

- Возможность «Сохранить текст в переменную» через контекстное меню:
  - Шаг: `saveVar | selector | varName`.
- В последующих шагах можно выбирать «Use variable» для параметризации.
- Объём операций с переменными в MVP ограничен сохранением и подстановкой.

***

## 9. UI/UX: темы и стили

- **JavaFX** + CSS для светлой/тёмной темы.
- Переключение темы через глобальные настройки.
- Минимум задержек при отрисовке.

***

## 10. Распределение функционала по фазам

**MVP (V1):**
- Два окна (WebDriver + панель действий).
- Запись действий (клики, ввод, селекты, переключение вкладок).
- Таблица с редактированием, проверкой локаторов (подсветка, крестик).
- Сохранение/загрузка JSON.
- Воспроизведение сценариев.
- Генерация базового Java-теста в одном файле.

**Extended (V2):**
- Генерация PageObject-классов.
- Параметризация через CSV/JSON.
- Экспорт в Maven/Gradle структуру.
- Улучшенные проверки (asserts).

**Advanced (V3):**
- Автоматическая интеграция с кастомной Web-element-библиотекой.
- Сканирование PageObject-классов по аннотациям.
- Генерация тестов с вызовом существующих геттеров.
- Интеграция с Allure @Step, TmsLink и т.п.

***

**Итог:** данная спецификация задаёт чёткий план для разработки IDE-подобного GUI-инструмента записи и генерации автотестов, обеспечивая кроссплатформенность, гибкость, интеграцию с вашей библиотекой и поэтапное добавление возможностей.
