# Опции колонки ElementType
Данная колонка описывает с каким веб-элементом будут производиться действия. Сами веб-элементы связаны с нашим фреймворком.

| ElementType    | Веб-элемент на странице                             | Описание                                                                               |
|----------------|-----------------------------------------------------|----------------------------------------------------------------------------------------|
| Button         | //button                                            | Обычная кнопка на странице                                                             |
| LinkButton     | //a                                                 | Кнопка или текст с ссылкой                                                             |
| TabButton      | `//div[@role='tab']`                                | Табы на странице. Например, таб "Необработанные" на странице Заявок                    |
| Field          | //input                                             | Обычное поле для ввода                                                                 |
| RichField      | `//*[@data-testid='form-richTextEditor']`           | Поле с возможностью форматирования текста. Есть в публикациях                          |
| Select         | `//*[(@data-testid='form-select']`                  | Текстовая выпадашка с использованием поиска. Например, при выборе шаблона заявки       |
| Dropdown       | `//ul[(contains(@class, 'ant-dropdown-menu')]`      | Выпадашка на кнопке. Например, при процессинге кандидата по воронке                    |
| CheckBoxButton | `//label[contains(@class, 'ant-checkbox-wrapper')]` | Квадратная кнопка для выбора множества или необязательного выбора.                     |
| RadioButton    | `//label[(contains(@class, 'ant-radio-wrapper')]`   | Круглая кнопка для выбора. Например, выбор пола при создании Кандидата                 |
| DatePicker     | `//*[(@data-testid='form-picker]`                   | Выбор даты                                                                             |
| Unknown        | -                                                   | Заглушка. Проставляется при использовании особых действий. Например, при смене вкладки |
