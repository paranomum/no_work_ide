# Воспроизведение и прогон тест плана
## Воспроизведение
Для воспроизведение тест-плана выберите домен, на котором хотите его воспроизвести и откройте браузер.
После открытия браузера у вас есть несколько вариантов для запуска сценария:
- Запуск всего сценария с 1 шага
- Запуск сценария с выделенного шага
- Запуск только выделенного шага

Запуск всего сценария можно выполнить при нажатии на кнопку стрелки правее от кнопки открытия браузера.
Запуск с конкретного шага или только выделенного шага можно сделать через контекстное меню.

## Остановка
Если вам требуется по каким либо причинам остановить прогон теста, у вас есть два варианта остановки
- Плавная остановка. Для этого достаточно нажать на "кнопку прогона" повторно. В таком случае программа завершит начатый шаг и остановит сценарий.
- Принудительная остановка. Для этого требуется вызвать контекстное меню "кнопки прогона" и выбрать "Force stop". Прогон сценария сразу остановится.

## Завершение прогона
При завершении прогона появится окно с результатами. Если произошло падение, программа выведет что было не так и отметит упавший шаг красным.

Независимо от результата прогона, вам будет предложено посмотреть ответы бекенд запросов, если вы их использовали, и завести баг-репорт. 
> Если вы еще не сконфигурировали интеграцию с Ягой, вы можете просмотреть инструкцию в разделе "Интеграция с Ягой"

При заведении баг репорта из упавшего теста, автоматически будут заполнены шаги воспроизведения до момента падения, фактический результат с ошибкой и прикреплен curl в виде .txt файла, если упал backend запрос.
> Всегда проверяйте какая ошибка была выделена с помощью TestRecorder, тк данные могут быть расплывчаты или вовсе отсутствовать.
