# Переменные
Переменные - именнованные данные, которые вы можете использовать для сохранения и переиспользования данных (например, id заявки)
## Создание и редактирование переменных
Создать переменные можно 3 способами:
- При редактировании поля value, можно вытащить значение, которое там находится и создать из него переменную. Неважно что это - метод или просто данные из серии вашей почты, итоговое значение запишется в переменную перед прогоном теста
- Через "Настройки" → вкладка "Переменные" можно добавить переменную. Достаточно нажать на "+" и ввести имя и значение, а затем сохранить.
- При вытаскивании значения из ответа запроса. В таком случае переменная создастся автоматически, но лучше ее переименовать и дать ей более короткое и говорящее название.
Для редактирования переменной достаточно перейти на вкладку "Переменные" в настройках.
>Не рекомендуется менять значения переменных, которые вы вытаскиваете из ответов запросов.
## Использование переменных
Переменные можно подставлять и использовать в двух случаях:
- При вводе данных в поле \ при выборе опций из выпадашек (то есть для действий fill и selectOption'ов)
- При подставлении данных в тело бек запроса. Подробнее об этом можно почитать в разделе "Использование backend запросов"
## Сохранение переменных
**Методы сохраняются на уровне теста, а не приложения!** Чтобы добавить их, можете обернуть сценарий с нужными переменными в кастомный метод и вставить его в тест. Все подтянется автоматически.
