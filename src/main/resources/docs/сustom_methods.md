# Кастомные методы (сustomMethods)
Кастомные методы - это ваши тестовые сценарии, которые вы можете переиспользовать в других тестах 
>Например создание и согласование заявки или создание кандидата можно сохранить как кастомный метод и подставлять в тесты для офферов
## Создание и сохранение кастомных методов
Есть два варианта создания кастомных методов
- Сохранить кастомный метод из выделенных шагов в вашем тесте
- Сохранить сценарий и добавить его в приложение как кастомный метод через "Меню" → "Настройки" → "Кастомные методы"
В обоих случаях данные автоматически синхронизируются и вы сможете сразу использовать свои методы. Сами методы сохраняются на уровне приложения, а не теста, поэтому вы можете в любой момент использовать их.
## Использование кастомных методов
Для того, чтобы подставить кастомный метод, выберете в колонке "Actions" опцию "customMethod". Высветится окно для выбора из существующих кастомных методов.
## Редактирование кастомных методов
Если вам надо немного поменять работу метода, вы можете "раскрыть" его в вашем сценарии для редактирования через опцию "Изменить пользовательский метод" в контекстном меню. Не забудьте сохранить его перед запуском с помощью опции "Сохранить и свернуть пользовательский метод" в контекстном меню.
> Кастомный метод поменяется для абсолютно всех тестов. Будьте аккуратны при его редактировании.=
## Сохранение теста с кастомным методом
При использовании кастомного метода в тесте и сохранении важно понимать, что метод сохраняется на уровне приложения, а не теста. Если вы планируете скинуть ваш тест своему коллеге, лучше сохраните тест в развернутом виде. В таком случае кастомные методы будут "развернуты" и сохраняться как обычные шаги в тесте.
