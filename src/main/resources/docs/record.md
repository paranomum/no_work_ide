# Запись и настройка тест плана
## Автоматический захват действий из браузера
При открытии браузера и нажатии на кнопку "Начать запись", начнется отслеживание ваших шагов в браузере. Каждый шаг будет записываться в таблицу и впоследствии их можно будет воспроизвести
Исходя из ваших кликов будут заполнены следующие данные:
- Тип действия в колонку Actions
- Xpath элемента в колонку Selector
- Значение, которое вы вписали или выбрали в колонку Value
- Тип веб-элемента исходя из xpath в колонку ElementType

При захвате не используются "особые" действия, кроме switchTab.
Если вы столкнулись с проблемой при записи, обратитесь к разделу "Нюансы при работе с TestRecorder".

## Захват backend запросов
Если вам требуется захватить бек запрос, откройте браузер и нажмите кнопку "Захватить". В выпадающем списке выберите:
- "Захватить по url", если вы знаете какой запрос вам нужен. Введите url запроса, который вам нужен
- "Захватить все запросы" для последующего выбора нужных запросов из списка.
- Для остановки режима "Захватить все запросы" нажмите опцию "Остановить захват"
Далее сохраненные бек запросы можно настроить и использовать в тестовом плане. Подробнее про backend методы можно прочитать в разделе "Использование backend запросов"

## Добавление шага руками
При нажатии на кнопку "+" в верхнем левом углу добавится шаг, который вы можете самостоятельно настроить, используя:
- Доступные действия (колонка Action) - обязательное поле
- Настроив путь до веб-элемента (колонка Selector)
- Введя требуемое значение для заполнения (колонка Value)
- Определив тип веб-элемента (колонка ElementType)
Дополнительно вы можете добавить комментарий для действия

Обратите внимание, что если вы работаете с common действиями, заполнение Action, Selector и ElementType обязательно.
При захвате ваших действий из браузера, все данные, кроме комментария, заполняются автоматически.

## Замедление теста
Если вам требуется внимательнее посмотреть на воспроизведение теста, вы можете использовать кнопку "Замедлить".
Работа с замедлением делится на 2 вида:
1) Добавление задержки между шагами с использованием внутренней задержки. Позже вы можете ее убрать. Данные не сохраняться в сценарии.
2) Добавление пауз после каждого шага с помощью кнопки "Добавить шагом". При использовании этой опции после каждого шага вашего сценария будет добавлен дополнительный шаг "pause" с указанным количеством секунд. Данные шаги сохранятся в сценарии.
