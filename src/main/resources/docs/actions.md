# Опции колонки Actions
## Common действия
Под "базовыми" действиями подразумеваются простые действия в браузере - клик, заполнение поля или выбор значения из выпадающего списка

| Действие           | Описание                                                    | Возможные значения (Value)                                     | Веб-Элементы (ElementType)                           |
|--------------------|-------------------------------------------------------------|----------------------------------------------------------------|------------------------------------------------------|
| click              | Нажатие на кнопку/чекбокс                                   | Не поддерживается                                              | Button, LinkButton, TabButton, CheckBox, RadioButton |
| fill               | Заполнение поля (без выбора значения из выпадающего списка) | Значение, которое будет введено в поле                         | Field, RichField                                     |
| selectOption       | Выбор опции из выпадающего списка                           | Значение, частично совпадающее с нужной опцией                 | Select, Dropdown                                     |
| selectOptions      | Выбор нескольких опций из выпадающего списка                | Значения, частично совпадающие с нужными опциями через запятую | Select, Dropdown                                     |
| selectExactOptions | Выбор опции из выпадающего списка по конкретному значению   | Значение, полностью совпадающее с нужной опцией                | Select, Dropdown                                     |
| fillDate           | Заполнение даты                                             | Не поддерживается                                              | DatePicker                                           |
| clear              | Очистить значение                                           | Не поддерживается                                              | Field, RichField, Select                             |


## Spec_actions действия
Под специальными действиями подразумевается использование методов из фреймворка автотестов, которые могут упростить работу

| Метод           | Описание                                                                                                                             | Возможные значения (Value)                              |
|-----------------|--------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------|
| pause           | Пауза                                                                                                                                | числовое (количество секунд)                            |
| refreshPage     | Перезагрузка страницы                                                                                                                | Не поддерживается                                       |
| waitLoadingPage | Ожидание прогрузки страницы                                                                                                          | Не поддерживается                                       |
| fillData        | Заполнение данных анкеты кандидата, офера, заявки (только обязательные поля)                                                         | Не поддерживается                                       |
| assertExists    | Проверка, что элемент существует                                                                                                     | Не поддерживается (Берется зачение из колонки Selector) |
| assertNotExists | Проверка, что элемент не существует                                                                                                  | Не поддерживается (Берется зачение из колонки Selector) |
| specialAction   | Для генерации автотестов. Если требуется сделать какое-то действие, вы можете выбрать этот метод и написать что именно в комментарии | Не поддерживается                                       |
| switchTab       | Смена вкладки                                                                                                                        | Не поддерживается                                       |
| open            | Открыть ссылку на страницу                                                                                                           | Ссылка на страницу (ПОЛНОСТЬЮ)                          |

## CustomMethod и useBackendMethod
Данные действия отвечают за воcпроизведение кастомных методов и запросов на бек. В колонку "Value" вставляется название вызываемого метода или запроса.
