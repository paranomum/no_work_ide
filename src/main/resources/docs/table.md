# Таблица действий в TestRecorder
Таблица действий - таблица, в которой по шагово описан тест-план.
Таблица состоит из 6 колонок:
- `#` - колонка для нумерования шагов воспроизведения
- Actions - колонка с выбором проигрываемого действия. Подробнее можно посмотреть в "Опции колонки Actions"
- Selector - колонка с "путем" до веб-элемента. Все xpath основаны на нашем фреймворке.
- Value - колонка со значением для действия. Подробнее о том, где ее можно применить, описано в таблице в "Опции колонки Actions"
- Comment - колонка для комментариев к действиям
- Element Type - колонка с типом веб-элемента, с которым будет производиться взаимодействия. Все подробности есть в таблицах в "Опции колонки Actions" и "Опции колонки ElementType"

## Дополнительный функционал полей
Для двух полей (selector и value) были добавлены специальные кнопки для удобства работы
### Поле в столбце Selector
1) Кнопка "мишень" - найти и выбрать путь до элемента (xpath) на странице
Если нажать на эту кнопку, приложение начнет фиксировать ваши действия в браузере с желтой подсветкой. Данная подсветка указывает на то, какой элемент выделится при нажатии.
Советы по использованию:
* Когда только нажимаете на "мишень", лучше нажать не на контент окна, а на рамку, чтобы переключиться на работу с браузером перед кликом на элемент
* Когда выбираете элемент, лучше наводиться на текст этого элемента. Тогда xpath с большей вероятностью будет проанализирован под наш фреймворк тестов (иначе может подтянутся слишком точный путь до элемента, что снижает стабильность)
2) Кнопка "лупа" - подстветить элемент по xpath на странице
Если нажать на эту кнопку, приложение подсветит желтым тот элемент, который будет найден по пути, введеному в поле selector
Советы по использованию:
* Чтобы было лучше видно выделенный элемент, стоит "разобрать" все приложения, который перекрывают браузер
### Поле в столбце Value
1) Кнопка "$" - использовать существующую переменную
Если у вас есть переменная (например из ответа бек запроса), которую вам надо ввести в поле или выбрать из "выпадашки", используйте эту функцию. При нажатии на эту кнопку появится окно для выбора  одной из существующих переменных.
2) Кнопка "+" - добавить переменную из значения в поле
Если вы ввели какое-то значение и хотите "прокинуть" его в другие поля для заполнения или выбора, используйте эту кнопку. При нажатии появится окно с вводом имени переменной. После ввода имени и сохранения, в поле подставится переменная.
3) Кнопка "указателя" - использовать метод для генерации значения
Бывают моменты, когда вам надо сгенерировать уникальные данные (например, телефон для кандидата или почта). Для этого можно воспользоваться методами для генерации данных.
* addUuid - добавляет uuid в конце вашего значения. Например, addUuid(text) вернет text_ccb6737b-9f83-413f-8192-3938ff57faef
* generateEmail() - генерирует email из кусочков сгенерированного uuid
* generatePhoneNumber() - генерирует номер телефона с 7 в начале

## Контекстное меню таблицы
Контекстное меню состоит из следующих опций:
- Удалить - удаляет выделенные поля
- Отметить \ снять метку - выделяет шаг. Помогает для визуализации проблемных мест
- Запустить сценарий с этого шага - запуск сценария с выбранного шага
- Выполнить только этот шаг - воспроизведения только выделенного шага
- Создать метод из шагов - создание customMethod из выделенных шагов
- Изменить пользовательский метод - применяется только к "свернутому" customMethod. Позволяет редактировать метод из теста.
- Сохранить и свернуть пользовательский метод - применяется только к "развернутому" customMethod. Сохраняет и сворачивает кастомный метод

Если выделить более 2х шагов, с помощью опции "Создать метод из шагов" вы можете создать свой кастомный метод, который сможете переиспользовать в других тестах.
Если у вас уже есть кастомный метод в тесте, который вы хотите изменить, вы можете сделать это с помощью опции "Изменить пользовательский метод".
Когда вы закончите редактирование, используйте "Сохранить и свернуть пользовательский метод" для применения ваших изменений.
Подробнее о работе с customMethods описано в разделе "Кастомные методы (сustomMethods)"
