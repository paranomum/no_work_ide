# Сохранение данных и тест плана
При сохранении у вас есть возможность сохранить тестовый сценарий в "разных видах"

## Сохранение теста
Данная опция позволяет сохранить сценарий в том виде, в котором он представлен в таблице.
Сценарий будет сохранен в виде .json структуры и позже вы сможете его открыть в TestRecorder.
## Сохранение развернутого теста
Если вы использовали кастомные методы, то эта опция позволит сохранить сценарий с развернутыми кастомными методами. Это требуется, когда вы не уверены в том, что у вашего коллеги есть кастомный метод, но сценарий требуется не только вам.
Сценарий будет сохранен в виде .json структуры и позже вы сможете открыть его в TestRecorder.
## Сохранение шаблона автотеста
Если вы хотите создать шаблон для написания автотеста, используйте этот метод.
Опция все еще находится в разработке и шаблоны сыроваты.
