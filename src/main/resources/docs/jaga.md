# Интеграция с Ягой
Данная интеграция позволяет ускорить процесс заведения баг-репорта, используя результаты прогона TestRecorder

## Настройка интеграции с Ягой
Для того, чтобы начать пользоваться интеграцией с Ягой, требуется настройка.
Зайдите в "Меню" → "Настройки" → Вкладка "Настройка Яги".

Шаги настройки интеграции:
1) Введите свои данные пользователя и нажмите кнопку "Проверить". Если возникла ошибка, нажмите "Загрузить серты", перезагрузите приложение и повторите ввод данных с проверкой.
2) Если вы еще не загружали серты, нажмите на кнопку "Загрузить серты". Нажмите кнопку "Сохранить". Перезагрузите приложение.
3) Введите id вашего проекта из яги. Это можно посмотреть во вкладке network в девтулз. После ввода нажмите "Получить типы задач" и дождитесь загрузки.
4) Выберите те типы задач, которые вы будете заводить через TestRecorder.
5) Нажмите кнопку "Сохранить"

## Функциональные возможности
- Автоматическое подтягивание обязательных полей для выбранного типа из вашего пространства
- Генерация шагов воспроизведения
- Прикрепление файлов с возможностью предпросмотра
- Считывание ошибки на упавшем шаге
- Отправка баг-репорта из приложения

### Принцип работы генерации шагов воспроизведения
Есть два "сценария", по которым будут заполняться шаги воспроизведения
1) Если вы заводите баг-репорт через "Меню" → "Завести баг репорт", в шагах воспроизведения вставятся все шаги вашего сценария.
2) Если вы заводите баг-репорт из всплывающего окна о завершении прогона теста, в шагах воспроизведения подставятся шаги до падения и шаг самого падения

### Принцип работы прикрепления файлов
Есть два "сценария", по которым будет работать автоматическое прикпрепление файлов
1) Если вы заводите баг-репорт через "Меню" → "Завести баг репорт", никаких автоматически прикрепляемых файлов не будет 
2) Если вы заводите баг-репорт из всплывающего окна о завершении прогона теста и упавший шаг - запрос на бек, в ваш репорт автоматически будет прикреплен curl упавшего запроса в виде .txt файла
#### Прикрепление разных типов файлов
- Если вы прикрепляете картинку, она будет добавлена в Описание в блок "Вложения".
- Если вы прикрепляете НЕ картинку, файл будет отправлен в комментарии после создания задачи в яге
