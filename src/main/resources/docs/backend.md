# Использование backend запросов
Для ускорения тестирования с помощью TestRecorder, был добавлен функционал с вызовом бекенд методов. Для их использования сначала требуется настроить TrustStore и добавить домены. Как это сделать написано в разделе "Начало работы".

## "Сборка" бек методов
Для того, чтобы добавить бек запросы в свой сценарий, для начала их надо "собрать" с платформы. 
Вы можете воспользоваться кнопкой "Захватить" и использовать 1 из опций:
- "Захватить по url", если вы знаете какой запрос вам нужен. Введите url запроса, который вам нужен
- "Захватить все запросы" для последующего выбора нужных запросов из списка.
- Для остановки режима "Захватить все запросы" нажмите опцию "Остановить захват"

При выборе захваченных методов вы можете "провалиться" в них и сразу отредактировать. Подробное описание в "Настройка бекенд методов"

## Настройка бекенд методов
При переходе "Меню" → "Настройки" → Вкладка "Backend" вы увидите список своих методов. При выделении метода и нажатии на кнопку "Редактировать метод" высветится окно для редактирования запроса.
В этом окне вы можете изменить:
- Имя метода
- "Тип" метода
- "Путь" метода
- BodyType
- Токен
- Значения, которые будут подставлены в дто
- Значения, которые надо вытащить из ответа
### Токен
Если поле пустое, программа "стырит" ваши куки из драйвера и подставит эти данные перед тем, как сделать запрос.
Если поле не пустое, убедитесь, что тянете нужную переменную или нужный токен, иначе столкнетесь с 401 ошибкой.
### Изменение значений в теле запроса
Чтобы не менять текстовое дто, был добавлен функционал парсинга полей из json для "переписывания" значений через переменные, генерации данных или просто для подставления другого значения введеного руками.
Для того, чтобы вытащить поля для редактирования значения, нажмите кнопку "Разобрать поля из запроса". В таблице появятся все пути до полей, которые были найдены.
С помощью кнопки "+" вы можете самостоятельно добавить поле.
С помощью кнопки "-" вы можете удалить поле из таблицы
> При парсенге, вытаскиваются не абсолютно все поля! Если в запросе есть список, будет выделен только 0 элемент. Если вам надо поставить другие элементы, скопируйте нужный путь и подставьте требуемый индекс.

> Перед тем, как начать работать с таблицей, удалите все поля, которые вы не собираетесь изменять. В противном случае у вас проставятся пустые значения при прогоне.

Когда вы привели таблицу в порядок, используйте колонки "Method" и "Arg/Variable" для редактирования:
- Метод "addUuid" - добавляет _uuid к значению из колонки "Arg/Variable"
- Метод "generateEmail" - генерирует email. Заполнение колонки "Arg/Variable" не требуется
- Метод "generatePhoneNumber" - генерирует номер телефона, начинающийся с цифры 7. Заполнение колонки "Arg/Variable" не требуется
- Метод "value" - использует значение из колонки "Arg/Variable"
- Метод "use variable" - при нажатии появится окно для выбора переменной, которую требуется подставить. колонка "Arg/Variable" заполнится автоматически
После редактирования сохраните изменения с помощью кнопки "Save"
> Старайтесь использовать переменные. Так ваш сценарий будет проще отредактировать и переиспользовать вашим коллегам
### Сохранение данных из ответа в переменную
Работа с ответом запроса нужна для вытаскивания и сохранения данных для дальнейшего переиспользования.
Для начала работа, распарсите поля ответа с помощью кнопки "Разобрать поля ответа". После удалите ненужные вам поля
С помощью кнопки "+" вы можете самостоятельно добавить поле.
С помощью кнопки "-" вы можете удалить поле из таблицы.
> При парсенге, вытаскиваются не абсолютно все поля! Если в запросе есть список, будет выделен только 0 элемент. Если вам надо поставить другие элементы, скопируйте нужный путь и подставьте требуемый индекс.

> Удаляйте из таблицы поля, значения которых вы не будете использовать! В противном случае у вас просто будет скопление переменных, в которых будет сложно разобраться

После формирования таблицы, для каждого поля введите удобное название переменной и сохраните изменения с помощью кнопки "Save"

> Используйте говорящие названия. Так ваш сценарий будет проще "читать" и переиспользовать вашим коллегам
## Использование бекенд методов
Когда вы настроили метод, вы можете добавить его в тест с помощью действия "useBackendMethod". При выборе этой опции, высветится окно с выбором сохраненных бек методов.
## Сохранение бекенд методов
**Методы сохраняются на уровне теста, а не приложения!**
Чтобы добавить бек методы, которые вы уже успели настроить, можете обернуть сценарий с нужными запросами в кастомный метод и вставить его в тест. Backend методы подтянутся автоматически.
